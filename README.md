# SettleBridge

Agent-to-agent settlement on HSK Chain via HashKey Smart Payment (HSP).

Built for the **HSK Chain Horizon Hackathon** (DoraHacks) — Track 2: Agent Payments & A2A Settlement.

## Idea
A PayerAgent hires a WorkerAgent for a small task. When the work is delivered and verified, the two agents settle the payment through HashKey Smart Payment (HSP) on testnet — leaving a verifiable, auditable on-chain trail of the whole agent-to-agent transaction.
